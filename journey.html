Chapter 01
Where It
All Began

Growing up in the Philippines, I was drawn to computers long before I understood what they were truly capable of. There was something magnetic about the idea that a blank screen could become anything — a game, a tool, a story, a business.

I started tinkering with design first. Layouts, colors, typography — the visual logic of things. Then code found me, and everything clicked. The ability to make something real from nothing but logic and intention felt like a superpower.

That feeling hasn't left me. It's the reason I build the way I do — with both aesthetic precision and technical depth, treating every project as a chance to do something that actually matters.

"Make it work. Make it beautiful. Make it matter."
Self-taught foundation, constantly expanding
Davao City, Philippines based
Design-first, code-second thinking
Open to remote & global opportunities
Driven by craft, not just output
Chapter 02
Milestones &
Moments
2021 — Start
First Line of Code
Opened a YouTube tutorial, typed "Hello World," and felt something shift. HTML and CSS became an obsession almost overnight — rebuilding sites I liked from scratch just to understand how they worked.
HTML CSS Self-taught
2022 — Growth
Into JavaScript & Design Systems
JavaScript unlocked interactivity. I started building small tools, animated interfaces, and diving into design principles — typography, grids, color theory. This was when design and development merged for me into a single discipline.
JavaScript UI Design Figma
2023 — Momentum
First Real Projects & React
Started building for real clients and personal projects that shipped. Picked up React and modern tooling. Began to understand the difference between code that works and code that lasts.
React Node.js Client Work
2024 — Depth
Full-Stack & Product Thinking
Expanded into backend, databases, and APIs. Started thinking less about features and more about products — user flows, business logic, the whole picture. Built systems that others actually use daily.
Full-Stack Databases REST APIs
2025 — Now
Refining the Craft
Focused on production-quality work — performance, accessibility, and the kind of polish that separates good from memorable. Open to collaborations and opportunities that push me further.

Chapter 04
How I
Think
01
Craft Over Speed
Fast shipping matters, but not at the cost of quality that embarrasses you later. I'd rather take the extra hour to make it right than spend a week undoing it.
02
Empathy as UX
Great interfaces come from genuinely caring about the person on the other end. Every decision — font size, hover state, error message — is a conversation with a human.
03
Never Stop Unlearning
The best developers I know hold their opinions loosely. The field evolves. What made sense two years ago might be tech debt today. Stay curious, stay humble.
04
Build With Purpose
Code without context is just noise. I want to work on things that solve actual problems — for real people, in real situations, with outcomes that outlast the sprint.

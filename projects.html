01 / Featured Project

UM Org Connect

Student Organization Event Management & Governance System
PHP MySQL QR Code API HTML5 / CSS3 JavaScript RBAC

UM Org Connect is a centralized web-based management system designed specifically for campus student organizations. It automates event management, attendance tracking, financial budgeting requests, and administrative document clearance workflows into a single unified platform.

// Key Capabilities & Modules
⚡ QR Attendance System
Generates unique QR codes for events and enables instant mobile scanning for attendee check-ins and time logs.
📊 Budgeting & Financial Tracker
Modules for student officers to submit expense proposals, monitor organization funds, and audit event expenditures.
📑 Document Clearance Workflow
Digital submission of event permits, venue requests, and post-activity evaluation reports to university administration.
🔐 Multi-Tenant RBAC
Granular permissions tailored for Student Members, Officers, Organization Advisors, and School Administrators.
02 / Featured Project

Attendify

Smart Classroom Attendance & Analytics Platform
PHP MySQL QR Scanner JavaScript Analytics Responsive UI

Attendify is a real-time QR-based attendance tracking platform created to modernize classroom attendance monitoring. By eliminating paper sign-in sheets, it saves valuable instructional time, prevents proxy attendance, and provides instructors with live attendance trends and automated reports.

// Key Capabilities & Modules
📱 Contactless QR Check-In
Dynamic QR code generation per class session enabling rapid student scanning directly from mobile screens.
📈 Real-Time Analytics
Visual dashboards detailing student presence rates, tardiness logs, and attendance percentages across terms.
⚡ Automated Export & Reporting
One-click export of complete attendance records into spreadsheet and PDF formats for academic reporting.
👤 Student Self-Service Portal
Allows students to track their own attendance standing and receive low-attendance warning alerts.
03 / Featured Project

NCIP-EAP

National Commission on Indigenous Peoples — Scholar Portal
PHP MySQL Web Portal Document Management Database Architecture Admin Dashboard

NCIP-EAP (Educational Assistance Program) is an end-to-end scholarship management portal built for the National Commission on Indigenous Peoples. It streamlines the scholarship lifecycle for Indigenous Cultural Communities (ICCs/IPs) — from online application filing to document verification and educational grant disbursement tracking.

// Key Capabilities & Modules
🎓 Online Scholar Application
Accessible application portal for IP scholars with real-time status tracking throughout the evaluation phases.
📁 Document Audit & Verification
Digital upload and verification system for grade slips, Certificate of Tribal Membership (CTM), and enrollment proofs.
🛡️ Central Admin Dashboard
Comprehensive administrative portal for regional officers to manage scholar quotas, approvals, and grant disbursement logs.
🔔 Status Tracking & Alerts
Automated application feedback keeping applicants and regional handlers synced on missing requirements and grant releases.

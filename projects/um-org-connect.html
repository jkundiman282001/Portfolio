Case Study 01 // Student Governance System

UM ORG CONNECT

A comprehensive web application designed to streamline student organization event planning, budget proposals, document clearances, and QR-based attendance tracking.

Role
Lead Web Developer
Category
Student Governance & Web Management
Tech Stack
PHP, MySQL, JavaScript, QR Code API
Deployment
Internal Web Server
// Executive Summary

The Challenge & Vision

University student organizations process dozens of event approvals, financial liquidations, and attendance rosters every semester. Traditionally, these processes relied on physical paper clearance forms, manual sign-in sheets, and fragmented communications across spreadsheet files.

UM Org Connect was engineered to solve these administrative bottlenecks by creating a single, cohesive web platform. It digitizes student organization workflows — allowing officers to submit proposals online, advisers to review budgets in real-time, and event organizers to mark attendance instantly via QR code scanning.

// System Modules

Core Capabilities & Architecture

⚡

QR Attendance Engine

Generates dynamic QR codes for each approved activity. Event personnel can scan member badges or mobile screens to record timestamped attendance automatically.

📊

Budgeting & Financial Tracking

Provides a structured module for submitting budget breakdowns, tracking organization fund balances, and auditing post-event expenses with receipts.

📑

Document Approval Workflow

Replaces physical paper trails with digital document submissions. Allows campus administrators to approve or request revisions on activity permits online.

🔐

Role-Based Access Control (RBAC)

Multi-tenant architecture enforcing strict permissions for Student Members, Executive Officers, Faculty Advisors, and University Administrators.

📅

Organization Event Calendar

Centralized campus-wide activity calendar preventing schedule conflicts between organizations and displaying upcoming student events.

📈

Reports & Analytics

Automates semester-end organizational evaluation reports, generating downloadable attendance statistics and financial compliance summaries.

// Engineering

Technology Stack
